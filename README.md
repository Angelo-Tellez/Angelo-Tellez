### 📌 Proyectos destacados

#### 🚗 GM Innovation Challenge — App OnStar/CAC ONE
Extracción y análisis de datos de redes sociales para un asistente conversacional automotriz.
- Módulo de extracción de datos vía **YouTube Data API v3** y **Meta Graph API** con autenticación OAuth2, integrado en Kotlin/Retrofit.
- Pipeline de análisis de sentimiento (**TF-IDF + Regresión Logística**) sobre ~2,000 comentarios etiquetados, a partir de un histórico de ~25,000 extraídos.

#### 💰 SIRAF — Sistema de análisis financiero para PyMEs
Plataforma para que pequeñas y medianas empresas evalúen su salud financiera.
- Backend con **FastAPI + PostgreSQL**, autenticación JWT y control de acceso por roles (Pyme/Contador).
- Cálculo automatizado de razones financieras con clasificación tipo semáforo.
- Presentado en **InnovaTecNM 2026 – Etapa Local, Región 4**.

#### 🍽️ Porké — PWA para restaurante
Aplicación web progresiva en producción real, usada por el restaurante para gestionar pedidos.
- Stack: **Next.js + Firebase**, con soporte offline vía Service Worker y notificaciones push.
- Integración de pagos con **PayPal API** y manejo de imágenes con **Cloudinary**.
